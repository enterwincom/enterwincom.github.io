## 📄 PDF 이미지 변환기 (PDF to Image)

PDF 문서의 특정 페이지를 이미지로 저장하거나, 전체 문서를 고화질 그림 파일로 변환해야 할 때 유용한 **웹 기반 PDF 변환 도구**입니다. 복잡한 설정 없이 PDF를 업로드하고 바로 이미지화할 수 있습니다.

---

### 🚀 주요 기능 및 사용 방법

브라우저에서 모든 과정이 이루어지는 빠르고 간편한 도구입니다.

1. **파일 업로드**: 변환하려는 PDF 파일을 선택하거나 영역에 끌어다 놓습니다.
2. **페이지 확인**: 업로드된 PDF의 페이지를 확인하고 변환을 준비합니다.
3. **이미지 변환**: 클릭 한 번으로 각 페이지를 고해상도 이미지(JPG/PNG)로 렌더링합니다.
4. **ZIP 다운로드**: 변환된 여러 장의 이미지를 하나의 **ZIP 압축 파일**로 묶어 간편하게 저장합니다.

### 🛠 기술 스택 및 특징

* **Privacy Focused**: 서버로 파일을 전송하지 않고 사용자의 기기 내에서 직접 변환하므로, 중요한 문서 유출 걱정이 없습니다.
* **No Installation**: 무거운 PDF 편집 프로그램이나 뷰어 설치 없이 웹 브라우저만 있으면 어디서든 사용 가능합니다.
* **High Quality**: 텍스트와 이미지를 선명하게 유지하며 고품질 이미지 출력을 지원합니다.
