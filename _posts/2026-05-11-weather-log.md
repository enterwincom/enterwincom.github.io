## 🌤️ Weather Log (웨더 로그)

**Weather Log**는 사용자가 원하는 도시와 기간을 설정하여 과거의 기상 기록을 추적하고 데이터로 보관할 수 있게 도와주는 웹 기반 아카이빙 도구입니다. 복잡한 기상청 사이트를 헤매지 않아도 깔끔한 UI를 통해 날씨 데이터를 한눈에 확인하세요.

---

### 🔑 주요 특징 및 기능

1. **간편한 데이터 조회**: 전국 주요 도시의 위치 데이터를 기반으로 원하는 날짜 범위를 선택하여 즉시 조회합니다.
2. **시각적 가독성**: 최고 기온(빨강), 최저 기온(파랑), 그리고 일교차(강조)를 색상별로 구분하여 기온 변화를 직관적으로 파악할 수 있습니다.
3. **엑셀(Excel) 내보내기**: 화면에 표시된 표 데이터를 SheetJS를 이용해 `.xlsx` 파일로 변환, 오프라인 데이터 분석용으로 소장 가능합니다.
4. **모던 UI/UX**: 구글 스타일의 카드 레이아웃과 반응형 디자인을 적용하여 모바일과 PC에서 모두 쾌적하게 사용합니다.

---

### 🚀 사용 방법

*   **도시 선택**: 목록에서 조회를 원하는 지역을 선택합니다.
*   **기간 설정**: 시작일과 종료일을 입력합니다. (과거 데이터 기반)
*   **조회 및 저장**: '조회하기' 버튼으로 데이터를 불러온 후, 필요 시 '엑셀 저장' 버튼을 눌러 파일을 다운로드합니다.

### 🛠 기술 세부사항

*   **API**: Open-Meteo Archive API (고성능 기상 데이터 소스)
*   **Library**: `SheetJS` (강력한 엑셀 파일 생성 라이브러리)
*   **Font**: `Pretendard` (가독성 높은 프리미엄 서체)
