\## ☁️ Weather Log (날씨 기록 저장소)



과거의 날씨 데이터를 조회하고 기록하는 것은 단순한 호기심을 넘어 다양한 데이터 분석의 기초가 됩니다. \*\*Weather Log\*\*는 Open-Meteo API를 활용하여 전 세계 주요 도시의 과거 기온과 날씨 상태를 한눈에 파악하고, 이를 엑셀 파일로 소장할 수 있도록 돕는 웹 서비스입니다.



\---



\### 🌟 주요 기능



사용자 친화적인 인터페이스를 통해 복잡한 과정 없이 날씨 데이터를 추출할 수 있습니다.



1\. \*\*도시별 맞춤 조회\*\*: 서울, 강릉, 제주 등 국내 주요 도시의 위경도 데이터를 내장하여 간편하게 선택할 수 있습니다.

2\. \*\*기간 설정 아카이브\*\*: 시작일과 종료일을 지정하여 원하는 특정 기간의 기록만 정확하게 불러옵니다.

3\. \*\*상태 요약 정보\*\*: 최고/최저 기온은 물론, 일교차를 자동으로 계산하여 시각적으로 강조해 줍니다.

4\. \*\*엑셀(Excel) 다운로드\*\*: 조회된 데이터를 클릭 한 번으로 `.xlsx` 파일로 저장하여 오프라인에서 활용할 수 있습니다.

\### 🛠 기술 스택



\*   \*\*Frontend\*\*: HTML5, CSS3 (Custom Properties), JavaScript (ES6+)

\*   \*\*API\*\*: Open-Meteo Historical Weather API

\*   \*\*Library\*\*: SheetJS (XLSX) - 데이터 엑셀 변환용

\*   \*\*UI/UX\*\*: Pretendard 폰트와 모던한 카드 레이아웃 적용



\---



\### 💡 서비스 특징



\*   \*\*정확한 데이터\*\*: 공공 기상 데이터를 기반으로 한 신뢰도 높은 정보를 제공합니다.

\*   \*\*반응형 디자인\*\*: PC와 모바일 환경 어디서든 최적화된 화면으로 조회 가능합니다.

\*   \*\*일교차 분석\*\*: 단순히 기온만 보여주는 것이 아니라, 건강 관리에 유용한 일교차 정보를 별도의 스타일로 제공합니다.
